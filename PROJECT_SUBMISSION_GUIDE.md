# Project Submission Guide

Use this guide to prepare each portfolio project so it can be added to the website quickly and consistently.

## What To Send

For each project, please provide:

1. A text description using the template below
2. A folder of images for that project
3. An indication of whether the project should appear on the homepage featured section

## Recommended Folder Structure

Please organize the files like this:

```text
project-materials/
  eco-village-residence/
    hero.jpg
    gallery-1.jpg
    gallery-2.jpg
    gallery-3.jpg
    gallery-4.jpg
  green-roof-community-hub/
    hero.jpg
    gallery-1.jpg
    gallery-2.jpg
    gallery-3.jpg
```

Each project should have its own folder.

## Field Guide

### Required Fields

- `Title`: Full project name
- `Slug`: URL-friendly version of the title
  Example: `eco-village-residence`
- `Category`: Choose one:
  - `Academic`
  - `Professional`
  - `Research-Oriented`
- `Year`: Project year
- `Location`: City, country, or region
- `Role`: Your role in the project
- `Tools`: Comma-separated list
- `Keywords`: Comma-separated list
- `Tags`: Choose from:
  - `Academic`
  - `Professional`
  - `Sustainability`
  - `Urban`
  - `Research-Oriented`

### Project Text

- `Short Description`: Used on portfolio cards and project previews
- `Overview`: General introduction to the project
- `Concept`: Main design idea or spatial strategy
- `Sustainability / Research Focus`: Environmental, systems, or research-related content
- `Reflection`: What the project clarified, taught, or contributed to your practice

### Homepage Feature

- `Featured on Homepage`: Use `Yes` if the project should appear in the homepage featured section

### Image Notes

Use this to tell which image should be used where.

Example:

```md
Image Notes:
Hero image: hero.jpg
Gallery image 1: gallery-1.jpg
Gallery image 2: gallery-2.jpg
Gallery image 3: gallery-3.jpg
Gallery image 4: gallery-4.jpg
```

## Image Requirements

### Recommended

- `1` hero image per project
- `3-4` gallery images per project

### Best Formats

- `.jpg`
- `.png`
- `.webp`

### Recommended Size

- Hero image: at least `1800px` wide
- Gallery images: at least `1400px` wide

### Notes

- Landscape images work best for hero images
- Use clear, high-resolution exports
- Avoid screenshots with UI around them unless they are intentional diagrams

## Example Filled Project

```md
Title: Eco Village Residence
Slug: eco-village-residence
Category: Academic
Year: 2025
Location: Balkan Mountains, Bulgaria
Role: Lead Architectural Designer
Tools: Rhino, Grasshopper, ClimateStudio, Adobe InDesign
Keywords: Passive Design, Landscape Integration, Low-Impact Housing
Tags: Academic, Sustainability, Research-Oriented

Short Description:
A clustered housing proposal that merges terraced living with water-sensitive landscape systems.

Overview:
Eco Village Residence explores housing as an ecological settlement model. The project tests how clustered residential typologies can preserve landscape continuity while encouraging community life and reducing operational energy demand.

Concept:
The concept organizes housing volumes along contour-responsive terraces, creating a sequence of shared gardens, shaded pathways, and planted thresholds. Instead of imposing a rigid object on the site, the architecture follows the existing landscape logic.

Sustainability / Research Focus:
The proposal prioritizes passive solar orientation, thermal buffering, stormwater retention, productive planting, and compact material systems. The project also studies how density can coexist with landscape regeneration rather than replacing it.

Reflection:
This project reinforced my interest in architectural systems that are both environmentally performative and socially grounded. It also shaped my research direction toward climate adaptation through spatial design.

Yes
```

## Best Way To Share Everything

The easiest delivery format is:

1. One folder per project
2. One Markdown or text file per project using the template above
3. All project folders placed in one shared directory or zip file

Example:

```text
project-materials/
  eco-village-residence/
    project-info.md
    hero.jpg
    gallery-1.jpg
    gallery-2.jpg
    gallery-3.jpg
    gallery-4.jpg
  green-roof-community-hub/
    project-info.md
    hero.jpg
    gallery-1.jpg
    gallery-2.jpg
    gallery-3.jpg
```

## Optional Extras

If available, you can also include:

- Final presentation boards
- Diagrams
- Plans, sections, and elevations
- Render captions
- Project collaborators
- University, studio, or office name

These are optional, but useful.

## Final Notes

- Keep each text section concise and clear
- It is fine if some projects are more academic and others are more professional
- If you are unsure about a field, leave it blank and it can be completed later
- If a project has fewer than 4 images, that is completely fine
